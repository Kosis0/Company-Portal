# Company Portal

A streamlined, two-page Employee Self-Service (ESS) application designed for fast internal navigation and efficient profile management.

## 🚀 Features

* **Employee Self-Service (ESS):** Clean two-page interface for viewing worker profiles and accessing core internal options.
* **Responsive Layout:** Optimized for fast loading across desktop and mobile devices.

## 🛠️ Tech Stack

* **Frontend / Framework:** React (Vite)
* **Version Control:** Git & GitHub
* **Deployment & Hosting:** Vercel
